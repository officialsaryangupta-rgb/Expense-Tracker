# 💰 Expense Tracker

A simple and responsive **Expense Tracker Web Application** built using HTML, CSS, and JavaScript. It helps users manage their income and expenses, calculate their current balance, and keep track of transactions directly in the browser.

## 🚀 Live Demo

🔗 https://officialsaryangupta-rgb.github.io/Expense-Tracker/



---

## 📌 About The Project

The Expense Tracker is a beginner-friendly web application designed to help users manage their daily financial transactions.

Users can add income and expenses, select expense categories, edit or delete transactions, search transactions, and filter them by category.

The application uses **Browser LocalStorage** to save data, so the transactions remain available even after refreshing or reopening the browser.

## ✨ Features

- 💵 Add Income

## 🛠️ Technologies Used

### HTML5
Used to create the structure of the Expense Tracker, including forms, inputs, buttons, transaction history, and summary sections.

### CSS3
Used for styling the application, creating cards, layouts, buttons, spacing, colors, and responsive design.

### JavaScript
Used to implement the main functionality of the application, including:

- DOM Manipulation
- Event Handling
- Arrays and Objects
- Functions
- Dynamic HTML Elements
- Search and Filtering
- Transaction Management
- Balance Calculation

### LocalStorage
Used to store income and expense data inside the browser so that data is not lost after refreshing the page.
